# SSIS Packages

Create these packages in Visual Studio / SSDT:

- `Load_Customers.dtsx`
- `Load_Products.dtsx`
- `Load_Sales.dtsx`
- `Load_DimCustomer.dtsx`
- `Load_DimProduct.dtsx`
- `Load_FactSales.dtsx`
- `Master_ETL.dtsx`

The `.dtsx` files are intentionally not generated here because they are Visual Studio/SSIS project artifacts. Build them using the ETL flow documented in `Documentation/ETL_Flow.md`.
