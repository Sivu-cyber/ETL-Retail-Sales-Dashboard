# SSIS Packages

The repository should contain the actual SSIS packages from Visual Studio/SSDT.

## Package List

- `Load_Customers.dtsx`
- `Load_Products.dtsx`
- `Load_Sales.dtsx`
- `Load_DimCustomer.dtsx`
- `Load_DimProduct.dtsx`
- `Load_FactSales.dtsx`
- `Master_ETL.dtsx`

## Important

This documentation package does not fabricate `.dtsx` binaries. Commit the real packages generated by your completed SSIS project.

## Connection

Use an OLE DB connection to the `RetailSalesDW` SQL Server database.

Avoid hard-coding credentials in the project.
