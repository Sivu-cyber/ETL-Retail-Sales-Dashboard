# Power BI Dashboard

Create a Power BI report using:

- `dw.FactSales`
- `dw.DimCustomer`
- `dw.DimProduct`
- `dw.DimDate`

Recommended visuals:

- Total Sales KPI
- Total Quantity KPI
- Total Orders KPI
- Average Order Value KPI
- Sales by Month
- Sales by Category
- Sales by State
- Top 10 Customers
- Top 10 Products

Recommended slicers:

- Year
- Category
- State
