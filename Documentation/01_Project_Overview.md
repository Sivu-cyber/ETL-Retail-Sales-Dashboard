# Project Overview

## Objective

Build an end-to-end retail ETL pipeline that moves source CSV data into a SQL Server dimensional warehouse and prepares the data for Power BI.

## Scope

The project covers:

- Source ingestion
- Staging
- Validation
- Transformation
- Surrogate keys
- Incremental loading
- SCD Type 2
- Error handling
- Reconciliation
- Audit logging
- Power BI reporting

## Initial Data

- 10 customers
- 10 products
- 15 sales transactions
- 365 calendar dates

Invalid test data adds two deliberately bad transactions.
